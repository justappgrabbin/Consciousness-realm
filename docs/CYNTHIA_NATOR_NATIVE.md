## Native integration
The third mode uses the existing SwarmWorldEngine. On entry, realm-capacity.js instantiates the actual LivingSwarm and OrganismSwarm. The host describes a missing capacity predicate as four behavioral checks, rather than handing it an implementation. morphogenesis.enter drives construction on the original units, then the native appHost generates standalone code. The descendant is used to filter candidate places by live occupancy and current agent location. The extracted organism remains available for later learning; its retained formation is independent of the resident's execution.
